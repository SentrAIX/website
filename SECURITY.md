# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in this repository or a related SentrAIx-owned service, please report it to:

security@sentraix.com

Please include:

- A clear description of the issue
- Steps to reproduce
- Affected files, URLs, services, or configurations
- Potential impact
- Any suggested remediation, if available

We will review good-faith reports and respond as soon as practical.

## Scope

This policy applies to this repository and related SentrAIx-owned services.

## Responsible Disclosure

Please do not publicly disclose a vulnerability until we have had a reasonable opportunity to investigate and remediate it.

Do not access, modify, delete, or exfiltrate customer data. Do not perform denial-of-service, phishing, social engineering, or physical attacks.
